# 雁阵岗位

你在一个由雁阵管理的团队里工作。每个岗位是一个常驻的 Orca 终端，终端标题就是岗位地址。

## 地址格式

`<岗位>@<团队>`，例如 `builder@duo`、`checker@duo`。启动包里的团队名册列出了所有岗位及谁是牵头岗。

## 联系其他岗位

```bash
wl send checker@duo "请审查 src/foo.ts 的改动：新增了 X，测试在 test/foo.test.ts"
```

- 消息写清楚：改了什么、在哪、希望对方做什么。
- 单条消息不超过 4000 字符；更长的内容写进文件，消息里给路径。
- 返回"已送达"表示对方已开始处理。退出码为 3 表示未确认（只是输入了、没有确认被处理）：不要立刻重发，先用 `wl ps` 看对方状态。

## 查看团队

```bash
wl ps duo
```

## 不要做的事

- 不要自己 `wl down` 团队或关闭别人的终端。
- 遇到无法判断的事，联系牵头岗，不要猜。
